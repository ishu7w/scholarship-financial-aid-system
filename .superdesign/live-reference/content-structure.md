# ScholarAI — AI-Powered Scholarship Intelligence

## Business Context
- **Type/Industry:** EdTech / Scholarship Platform
- **What they do:** Match students with scholarships using explainable AI; provide institutions fair, auditable applicant ranking.
- **Target audience:** Students seeking funding; universities, foundations, government programs running selection.
- **Page goal:** Convert visitors to free student signup or institution pilot; establish trust via transparency and proof.

**Notable patterns:** 
- Color alternation: near-black text dominates; red used only for accents (eyebrow, "MOST POPULAR" badge, button highlights, testimonial marks, final CTA).
- Grid types: uniform 4-col for "Both Sides" features; uniform 3-col for pricing tiers; uniform 3-col for testimonials.
- Sticky header (nav remains fixed at top).
- No rounded corners; all elements square.
- Monospace typeface for body copy and stats; display typeface (display serif or slab) for headings with tight tracking.
- Two type families across page.
- prefers-reduced-motion respected (no auto-play, explicit state on accordion).
